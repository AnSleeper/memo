# 不许忘！（buyaowang）

轻便快捷的本地备忘录桌面应用。Windows 便携版，绿色免安装：数据、配置、缓存全部放在程序所在目录，绝不落 C 盘。

采用 [Tauri 2](https://tauri.app/) 构建：前端是零依赖的原生 HTML/CSS/JS，后端是一个 800 行左右的 Rust 单文件。

## 功能特性

- **树形条目**：任意层级嵌套，拖拽排序、换父级（上沿=插到前面，下沿=插到后面，中间=收为子条目）
- **待办管理**：勾选完成、置顶；整棵子树都完成的条目下次打开时自动沉到同级末尾
- **提醒**：自制年/月/日/时网格选时间，到点弹 Windows 系统通知（Reminder 场景，可穿透"请勿打扰"），点击通知唤起窗口
- **回收站**：软删除可恢复（回到原父级原位置），保留期可选 7/30/90 天或永久
- **搜索**：按标题与正文实时过滤，自动保留命中的祖先链
- **富文本正文**：contentEditable 编辑，自动保存；支持图片/视频/音频（≤200MB），拖放、Ctrl+V 粘贴均可，插在光标位置
- **智能粘贴**：聊天软件复制的"文字+图片"混排内容可原样粘贴，本地图片自动入库
- **媒体原文存储**：不做任何转码压缩；双击用系统默认程序打开原图；正文里删掉的媒体文件自动从磁盘清理
- **全局唤起**：默认 `Ctrl+Alt+Space` 随时呼出窗口，可自定义
- **托盘常驻**：关闭按钮可选"彻底退出"或"最小化到托盘"，支持开机静默自启
- **五套深色皮肤**：暗墨绿 / 暖琥珀 / 雾蓝灰 / 中性石墨 / 樱粉
- **细节**：无边框自绘标题栏、窗口位置大小自动记忆（校验不跑出屏幕）、单实例（再次启动唤起已有窗口）、Esc 逐层收起、Ctrl+N 新建、F2 重命名

## 数据格式

全部是明文文件，可直接用任何工具备份、同步、版本管理：

```
程序目录/
├── 不许忘.exe
├── 配置/settings.json     # 皮肤、快捷键等设置
├── 配置/窗口.json          # 记住的窗口位置大小
├── 数据/索引.json          # 条目树结构（可删除重建）
├── 数据/条目/<id>/正文.md  # 每条一个文件夹：正文（文本+媒体引用）
├── 数据/条目/<id>/媒体/    # 该条目的媒体文件
└── 数据/回收站/            # 软删除的条目与记录
```

## 构建

需要 [Rust](https://rustup.rs/) 和 [Node.js](https://nodejs.org/)：

```bash
npm install        # 安装 @tauri-apps/cli
npm run dev        # 开发调试
npm run build      # 打包 NSIS 安装包（bundle 输出在 src-tauri/target）
```

重新生成程序图标（改了封面素材后）：`python 工具/make_icons.py`（需要 Pillow）。

## 设计要点

- **路径沙箱**：后端所有文件读写仅限数据目录内部的相对路径，逐段拒绝 `..` 与绝对路径；外部文件只能经单向复制进入（且限媒体类型、≤200MB）
- **便携红线**：数据目录拒绝 C 盘；WebView2 缓存目录显式重定向到程序目录
- **大文件分片**：媒体经 base64 分 4MB 片写入，避免单次 IPC 负载过大
- **防抖保存**：索引 350ms、正文 450ms、设置 300ms，关窗/失焦强制落盘
- **单实例**：独占锁文件 + 唤醒标记轮询，第二次启动只唤起已有窗口
